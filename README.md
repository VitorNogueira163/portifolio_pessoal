# portifolio_pessoal

Status do Projeto: 🚀 Concluído

Este projeto foi desenvolvido como uma atividade acadêmica do curso de **Desenvolvimento de Sistemas** do **SENAI de Santo André**. O objetivo principal foi consolidar o domínio na estruturação web utilizando **HTML5 puro e semântico**, organizando de forma clara as minhas informações profissionais, projetos práticos e canais de contato.

---

## 🎯 Objetivo do Desafio

Desenvolver uma página web limpa, funcional e totalmente estruturada através de tags semânticas nativas, reproduzindo fielmente os padrões técnicos de um layout de currículo profissional com acessibilidade.

---

## 🛠️ Tecnologias e Ferramentas

* **HTML5 Semântico** — Estrutura global e marcação de conteúdo.
* **CSS3** — Ajustes de dimensionamento (como a foto de perfil embutida por `object-fit`).
* **Git & GitHub** — Controle de versão e hospedagem do código.

---

## 📝 Requisitos Implementados

O projeto cumpre rigorosamente todos os critérios de avaliação exigidos no desafio:

### 🧱 Estrutura 100% Semântica
Uso correto das tags estruturais para a melhor legibilidade e organização do código:
* `<header>` e `<nav>` gerenciando o menu de navegação por âncoras internas (`#sobre`, `#projetos`, `#contato`).
* `<main>` e `<section>` dividindo as áreas da página.
* `<footer>` para o encerramento formal com os dados institucionais.

### 👤 Seção "Sobre Mim"
* Apresentação pessoal detalhando a formação e trilha de aprendizado atual.
* **Foto de Perfil Configurada:** Dimensionamento correto exigido de **150x150px**, estilizada para manter a proporção perfeita do rosto.
* Lista limpa destacando habilidades essenciais (Banco de Dados, HTML5, CSS3, e Arduino).

### 📊 Tabela de "Meus Projetos"
Construção técnica de uma tabela utilizando a estrutura rígida (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`), integrando os links funcionais dos meus repositórios ativos:
1. **Site sobre a série YOU** (HTML5)
2. **Prática de estruturação de repositórios** (GitHub, HTML e CSS)
3. **Projeto em grupo - Lista de tarefas** (JavaScript)

### 📋 Seção "Entre em Contato" (Formulário)
* Formulário protegido e agrupado nativamente pela tag **`<fieldset>`**.
* Título encaixado de forma elegante na borda superior através da tag **`<legend>`**.
* Vínculo correto de acessibilidade entre as tags `<label>` e seus respectivos campos de entrada (`input`, `select` e `textarea`).

### 🔏 Rodapé Institucional
* Uso correto de caracteres especiais nativos (`&copy;` para renderizar o símbolo de direitos autorais).
* Hiperlinks dinâmicos integrados para disparos diretos de comunicação (`mailto:` para e-mail e `tel:` para ligações).

---

## 🚀 Como Executar o Projeto

Por se tratar de um projeto construído em HTML puro, você não precisa instalar dependências ou configuradores de ambiente:

1. Clone este repositório no seu computador:
   ```bash
   git clone https://github.com
   ```
2. Entre na pasta correspondente.
3. Abra o arquivo `index.html` diretamente em qualquer navegador de sua preferência (Chrome, Edge, Firefox, Safari).
